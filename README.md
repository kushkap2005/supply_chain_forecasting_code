# Supply Chain Forecasting & Optimization

SKU-level demand forecasting engine with inventory optimization for DC planning.
Models: **LSTM · XGBoost · ARIMA** | Optimization: **EOQ · Safety Stock · Reorder Point**

---

## Results Achieved

| Model | MAPE | RMSE | MAE |
|-------|------|------|-----|
| XGBoost | 7.21% | 34.87 | 17.20 |
| ARIMA (baseline) | 12.88% | 45.46 | 29.15 |
| LSTM | 14.00% | 46.30 | 31.27 |

**XGBoost achieves 44% lower MAPE than ARIMA baseline.**
Pipeline runs end-to-end in under 2 minutes on new data.

## How to Run on Your Computer

### Step 1: Clone / Download the project

Download the zip and extract it, or copy the folder to your machine.

### Step 2: Create a virtual environment

```bash
# Navigate to the project folder
cd supply_chain_forecasting

# Create virtual environment
python -m venv venv

# Activate it
# On Mac/Linux:
source venv/bin/activate
# On Windows:
venv\Scripts\activate
```

### Step 3: Install dependencies

```bash
pip install -r requirements.txt
```

This installs: `pandas`, `numpy`, `scikit-learn`, `xgboost`, `statsmodels`, `scipy`, `streamlit`, `plotly`

> **Note**: No PyTorch or TensorFlow needed — LSTM is implemented in pure NumPy.

### Step 4: Run the pipeline

```bash
python run_pipeline.py
```

This will:
1. Generate 60 SKUs × 3 years of synthetic demand data
2. Engineer lag features, rolling averages, promo flags
3. Train XGBoost (all SKUs), ARIMA and LSTM (per SKU)
4. Evaluate models and print comparison table
5. Run EOQ / safety stock / ROP optimization
6. Save all outputs to `outputs/`

Expected runtime: **~2 minutes**

### Step 5: Launch the Streamlit dashboard

```bash
streamlit run src/dashboard/dashboard.py
```

Opens at `http://localhost:8501` in your browser.

| `src/dashboard/dashboard.py` | 4-tab Streamlit app: forecast viz, optimization table, model comparison, feature importance |

## Key Technical Decisions

**Why XGBoost outperforms LSTM here?**
With 3 years of tabular data and rich lag/rolling features, XGBoost captures demand patterns better than the lightweight LSTM. In production, a deeper LSTM with more data and GPU training would be competitive.

**Feature Engineering highlights:**
- `roll_mean_28d` is the #1 feature (50% importance) — confirms trend momentum matters most
- `promo_flag` ranks 4th — validates that promotional lift is a significant demand driver
- `ewm_14d` outranks simple lags — exponential weighting better captures recency

**Inventory Optimization:**
- EOQ minimizes total ordering + holding costs per SKU
- Safety stock is computed using service-level Z-scores (95–99% per SKU)
- Fulfilment risk flags SKUs where days-of-supply < lead time → direct DC action trigger
